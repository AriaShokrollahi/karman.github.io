# Karman — AI-Powered Compliance Platform

یک Landing Page مدرن و فارسی برای پلتفرم هوش مصنوعی «کارمان» که با هدف بررسی، تحلیل و کنترل اسناد و محتوای سازمانی طراحی شده است.

## ✨ معرفی پروژه

Karman یک رابط کاربری مدرن برای معرفی یک پلتفرم هوش مصنوعی است که به سازمان‌ها کمک می‌کند فرآیند بررسی و ارزیابی اسناد و محتوای خود را سریع‌تر و هوشمندانه‌تر انجام دهند.

تمرکز اصلی این Landing Page روی ایجاد حس اعتماد، نمایش قابلیت‌های محصول و هدایت کاربر به سمت شروع استفاده از سرویس است.

## 🎯 هدف پروژه

هدف از طراحی این صفحه، ایجاد یک تجربه کاربری حرفه‌ای برای معرفی محصول و انتقال سریع ارزش پیشنهادی آن به کاربران است.

صفحه با استفاده از یک طراحی مینیمال، ترکیب رنگ مشکی و قرمز، کارت‌های اطلاعاتی و بخش‌های محتوایی ساختار یافته طراحی شده است.

## 🚀 بخش‌های اصلی

- Hero Section با معرفی محصول و CTA
- نمایش آمار و شاخص‌های کلیدی
- معرفی مسئله و راهکار
- نمایش قابلیت‌ها و امکانات پلتفرم
- معرفی فرآیند استفاده از سرویس
- نمایش مزایای استفاده از هوش مصنوعی
- بخش مربوط به قوانین و الزامات
- نمایش نمونه مشتریان / سازمان‌ها
- Call To Action پایانی
- Footer ساده و مینیمال

## 🎨 Design

طراحی رابط کاربری با تمرکز روی:

- طراحی مدرن و مینیمال
- رابط کاربری فارسی و RTL
- استفاده از فضای منفی مناسب
- سلسله‌مراتب بصری واضح
- CTAهای مشخص
- کارت‌های محتوایی
- گوشه‌های Rounded
- افکت‌های نور و Gradient
- ترکیب رنگ مشکی، سفید و قرمز
- Responsive Design
